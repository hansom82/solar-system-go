# Solar System

Интерактивная 3D-модель Солнечной системы на **Go + raylib-go**.

- Реальная физика: кеплеровы орбиты (эллипсы, Солнце в фокусе), периоды обращения и вращения, наклон осей и ретроградное вращение по данным NASA — все соотношения точны.
- Настоящие текстуры планет, Солнца и Луны (2K, вшиты в бинарник).
- Кольца Сатурна с делением Кассини, пояс астероидов с туманом, межпланетные затмения (тени тел на шейдере).
- Один самодостаточный бинарник — без установки зависимостей.

## Сборка и запуск

```
go build -o solar-system .
./solar-system
```

Требуется Go 1.21+ и OpenGL 3.3+. CGO не нужен. Так же собираются Windows и macOS:

```
env GOOS=windows GOARCH=amd64 go build -o solar-system.exe .
env GOOS=darwin  GOARCH=arm64 go build -o solar-system-mac .
```

## Управление

| Клавиша | Действие |
|---|---|
| `ПКМ + мышь` | вращение камеры вокруг цели |
| `W` / `S` | ближе / дальше |
| `A` / `D` | поворот вокруг цели |
| колесо мыши | зум |
| `1`…`9` | обзор: 1 — Солнце, 2…9 — Меркурий…Нептун |
| `0` | общий обзор системы |
| `SPACE` | пауза |
| `←` / `→` | скорость времени (вращение камеры замедляется пропорционально) |
| `M` | пропорции планет: стилизованные ↔ реальные |
| `C` | кинематографический облёт |
| `O` / `L` | орбиты / подписи |
| `R` | сброс положения тел |
| `F11` | полноэкранный режим |

## Заметки

- В режиме реальных размеров (`M`) Солнце уменьшено условно: при настоящем масштабе оно покрыло бы орбиту Меркурия, т.к. расстояния между орбитами стилизованы.
- При старте в консоль выводится таблица сверки физики с NASA (закон Кеплера III, периоды, наклоны).
